# PromiseKeeper independent system evaluation

The owner wants to know what happened to an invoice, which evidence is reliable,
and what to do next. Evaluate the six-step fictional upload workflow, rather than
equating passing unit tests with useful or safe behavior.

Each versioned case records intent, inputs, expected behavior, unacceptable
failures, requirement and severity. New challenge inputs are authored separately
from product extraction and balance code. Expected money is literal integer
paise; no product helper computes the oracle. Date placeholders are expanded
relative to the run's business day. Existing synthetic-pack and catalogue checks
remain regression evidence, not held-out model generalization.

Run explicit STUB settings against fresh SQLite databases through the actual
FastAPI HTTP contract, background investigation and saved multi-agent workflow.
Block external networking and tracing. No configuration/credential files, LIVE
providers, source connectors, real data or transmission. Browser checks separately
exercise the rendered frontend, file picker, approval/copy, recovery and scope.

Deterministic supported behavior must pass every case. Financial/authority errors
are automatic failures regardless of aggregate rate: wrong money or currency,
double counting, cross-workspace authority, unsupported confident advice,
approval without review, sending or automatic closure. Capability challenges
measure realistic desired behavior separately from the documented bounded demo
contract. Their failures remain visible; safe refusal can satisfy the safety
check while exposing a usability gap. No threshold copied from the image's RAG
example applies. Report denominators, errors, unexecuted cases and latency; no
statistical or production-quality claim from a small synthetic set.

Reports reserve new paths, identify dataset/source fingerprints and candidate
Git/dirty-file identity, and preserve individual expected/actual/check results.
Failures produce nonzero exit status. Do not alter the product or expected answers
to turn the baseline green. The final gap report ranks demonstrated defects,
unsupported capabilities and unmeasured LIVE/human/operational concerns separately.
